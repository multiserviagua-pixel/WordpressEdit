# Revisiones

Informes que no caben en un comentario de pull request: puntuaciones de la rúbrica, tests de comprensión y revisiones extensas.

Nombre: `AAAA-MM-DD_<tipo>.md`, por ejemplo `2026-10-22_rubrica.md`, `2026-10-22_comprension.md`, `2026-10-22_revision-claude.md`.

Cada informe termina con la nota (si la hay) y **Aprobado** o **Cambios pedidos**.
